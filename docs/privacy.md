# 隐私说明

SplashGuard 的设计前提是：**你的数据不出这台设备。**

## 1. 我们收集什么

**什么都不收集。**

- 无账号、无登录、无设备指纹
- 无统计 SDK、无崩溃上报、无广告 SDK
- 无云端规则同步、无远程配置

## 2. 数据存在哪里

| 数据 | 位置 | 保留 |
|---|---|---|
| 拦截日志（App 包名 / 域名 / 时间） | 应用私有内存 + SharedPreferences | 最多 200 条，覆盖写入，可一键清空 |
| 自定义规则 | 应用私有 SharedPreferences | 直到你删除 |
| 分应用选择 | 应用私有 SharedPreferences | 直到你删除 |
| 设置项 | 应用私有 SharedPreferences | 直到你卸载 |

全部位于 `/data/data/com.splashguard.app/`，其他 App 无法读取，卸载即彻底删除。
不写入公共存储，不生成任何导出文件。

## 3. 网络行为

**唯一的出站流量是 DNS 转发。**

- 你未被拦截的域名查询，会被转发到你在设置里指定的上游 DNS（默认 `223.5.5.5`）
- 这是任何 DNS 服务都必须做的事，否则你就上不了网
- 转发是**明文 UDP 直连上游**，不经任何第三方中转，不经我们的服务器（我们没有服务器）
- 被拦截的域名**根本不发出任何请求**，直接由本机返回 0.0.0.0 或 NXDOMAIN

验证方法：用任意抓包工具（如 PC 端 Wireshark 抓热点、或 Android 上的 PCAPdroid）
观察本应用的出站连接，除 UDP:53 发往你配置的上游外，不应有任何其他连接。

## 3.1 iOS 描述文件：隐私边界不一样，必须说清

iOS 端没有本机规则引擎（平台不开放本地 VPN entitlement），所以 `ios/` 目录下的描述文件
做的是另一件事：**把你设备上的全部 DNS 查询加密转发给一个上游解析器**，由它来过滤。

| | Android（本 App） | iOS（描述文件） |
|---|---|---|
| DNS 查询发往 | 你自己填的上游（默认 `223.5.5.5`，明文） | 描述文件里指定的 DoH/DoT 服务商 |
| 谁能看到你访问了哪些域名 | 你的运营商/上游（与不用本工具时相同） | **该服务商** |
| 过滤规则在哪 | 本机，可审阅 | 服务商侧，不可见 |
| SplashGuard 是否收到数据 | 否（没有服务器） | 否（同样没有服务器） |

**默认预设用的是第三方公共解析器**（AdGuard DNS），这意味着你信任它。
如果你不接受这一点，用 `python ios/make_profile.py --doh-url ...` 指向自建 DoH
（AdGuard Home / mosdns 等），隐私边界就回到和 Android 端一致——数据只经过你自己的服务器。
`ios/README.md` 第 4 节有命令。

## 4. 权限清单与理由

| 权限 | 为什么需要 | 可否拒绝 |
|---|---|---|
| `BIND_VPN_SERVICE` | 建立本地 VPN 隧道以接管 DNS 查询。这是整个功能的技术基础 | 拒绝则拦截功能不可用 |
| `FOREGROUND_SERVICE` / `..._SPECIAL_USE` | 让拦截在后台持续运行，避免被系统回收 | 拒绝则只能前台短时工作 |
| `POST_NOTIFICATIONS` | 显示常驻运行状态（Android 13+） | 可拒绝，仅少了状态通知 |
| `RECEIVE_BOOT_COMPLETED` | 重启后自动恢复拦截 | 可拒绝，需每次手动开 |
| `QUERY_ALL_PACKAGES` | 分应用页需要列出已安装应用 | 可拒绝，则分应用功能不可用 |
| `BIND_ACCESSIBILITY_SERVICE`（可选） | 自动点击「跳过」按钮 | 默认关闭，不开也不影响 DNS 拦截 |

**未申请**：读取短信/通讯录/位置/相机/麦克风/存储/设备标识符。

## 5. 无障碍服务的边界声明

无障碍是 Android 上权限最高的接口之一，因此这里写清边界：

- **只**在窗口切换后的 6 秒内工作，其余时间不响应事件
- **只**匹配文本为「跳过 / 跳过广告 / 关闭广告 / Skip / Skip Ad」的控件
- **只**点击宽度小于屏幕 60% 的控件（防止误点整块广告位）
- **不**读取、不记录、不上传界面上的任何其他文本内容
- **不**在 SplashGuard 自身界面内动作
- 该功能默认关闭，开关关闭后服务立即停止处理事件

## 6. 不做什么

- 不破解任何 App 的会员/付费功能
- 不伪造广告曝光、点击、转化数据
- 不修改、不代理、不注入任何 App 的 HTTPS 内容
- 不收集、不上传、不交易任何用户数据
- 不绕过任何应用的鉴权或付费墙

## 7. 合规提示

- 在中国大陆，《互联网广告管理办法》要求利用互联网发布广告应显著标明关闭标志、
  确保一键关闭。用户选择关闭开屏广告属于其自身权利，本工具只是把「手动点」变成「自动点」。
- 部分 App 的用户协议可能限制使用广告拦截工具。是否使用由你判断，风险自担。
- 本应用不上架 Google Play / 国内应用商店，仅侧载分发，避免与商店政策冲突。
