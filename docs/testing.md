# 测试用例

分三层：**单元测试**（无设备可跑）、**手工验收**（需真机）、**回归清单**。

## 一、单元测试（`./gradlew test`）

### T-DNS 报文解析与构造

| 编号 | 用例 | 期望 |
|---|---|---|
| T-DNS-01 | 解析标准 A 查询 `ads.pangle.io` | 返回小写域名 `ads.pangle.io` |
| T-DNS-02 | 解析多级域名 `a.b.c.example.com` | 完整还原，不丢标签 |
| T-DNS-03 | 报文长度不足 12 字节 | 返回 null，不抛异常 |
| T-DNS-04 | QDCOUNT = 0 | 返回 null |
| T-DNS-05 | 构造 0.0.0.0 响应 | QR=1、RA=1、RCODE=0、ANCOUNT=1、应答 A 记录为 0.0.0.0、TTL=60 |
| T-DNS-06 | 构造 NXDOMAIN 响应 | RCODE=3、ANCOUNT=0、ARCOUNT=0 |
| T-DNS-07 | 响应保留原查询 ID | ID 与查询一致 |
| T-DNS-08 | 原查询带 EDNS0 OPT | 响应 ARCOUNT=0，且总长度正确 |
| T-DNS-09 | 构造响应后解析器可回读域名 | 回读域名与查询一致（自校验） |

### T-RULE 规则匹配

| 编号 | 用例 | 期望 |
|---|---|---|
| T-RULE-01 | 规则 `example.com`，查询 `example.com` | 命中 |
| T-RULE-02 | 规则 `example.com`，查询 `a.b.example.com` | 命中（后缀） |
| T-RULE-03 | 规则 `example.com`，查询 `notexample.com` | 不命中（防子串误伤） |
| T-RULE-04 | 规则 `example.com`，查询 `com` | 不命中（不能反向命中父域） |
| T-RULE-05 | AdBlock 写法 `||gdt.qq.com^` | 归一化为 `gdt.qq.com` 并可命中 |
| T-RULE-06 | 规则含注释 `domain # note` | 注释被剥离 |
| T-RULE-07 | 空行、纯注释行 | 被忽略，不产生空规则 |
| T-RULE-08 | 查询带大小写 `ADS.Pangle.IO` | 归一化为小写后命中 |
| T-RULE-09 | 含协议头的非法规则 `https://a.com/x` | 归一化为 `a.com` 或拒绝并报行号 |

### T-PKT 封包

| 编号 | 用例 | 期望 |
|---|---|---|
| T-PKT-01 | 用查询包封装响应 | 源/目的 IP 与端口互换正确 |
| T-PKT-02 | IPv4 头 | 版本=4、IHL=5、协议=17、TTL=64 |
| T-PKT-03 | 总长度字段 | 等于 20 + 8 + payload 长度 |

## 二、手工验收（真机）

### F-01 基础开关
1. 安装 APK，首次打开点开关
2. ✅ 弹出系统「连接请求」VPN 授权框
3. ✅ 允许后 3s 内状态变为「运行中」，状态栏出现钥匙图标
4. 再次点击关闭
5. ✅ 钥匙图标消失，浏览器可正常上网

### F-02 拦截验证（核心）
1. 开启拦截，确认运行中
2. 在设置里加一条自定义规则：`example.com`
3. 手机浏览器访问 `http://example.com`
4. ✅ 页面打不开；首页日志出现 `example.com` 记录

### F-03 真实开屏效果
1. 开启拦截 + 无障碍
2. 桌面冷启动 B 站 / 知乎 / 小红书（先用系统「强行停止」确保冷启动）
3. ✅ 记录：是否还有开屏广告、停留时长、日志是否命中
4. 结果记入下表（每 App 一行），作为规则库迭代依据

| App | 版本 | 是否仍有开屏 | 停留(s) | 命中域名 | 备注 |
|---|---|---|---|---|---|
| （待真机填写） | | | | | |

### F-04 分应用
1. 切到「仅选中应用」，只勾选浏览器
2. 打开微信
3. ✅ 微信域名不被拦（无相关日志）
4. 打开浏览器访问 `example.com`
5. ✅ 仍被拦

### F-05 拦截模式切换
1. 切到 NXDOMAIN，保存
2. 访问 `example.com`
3. ✅ 报「域名不存在」类错误，而不是超时

### F-06 开机自启
1. 保持开关开启，重启手机
2. ✅ 30s 内钥匙图标自动出现，无需解锁 App

### F-07 无障碍边界（防误伤）
1. 只开无障碍，不开 DNS
2. 在备忘录里输入文本「跳过」
3. ✅ 不应发生任何点击
4. 打开有开屏广告的 App
5. ✅ 「跳过」被自动点击，且**没有**跳转到广告落地页（重点检查浏览器/商店是否被唤起）

### F-08 耗电与网速
1. 开启前后各测一次 `speedtest` 下行速率
2. ✅ 速率差异 < 5%（非 DNS 流量不过隧道）
3. 待机 8 小时后看电池页
4. ✅ SplashGuard 耗电占比 < 1%

### F-09 异常恢复
1. 到系统设置里「撤销」VPN 授权（或清除应用数据）
2. 打开 SplashGuard
3. ✅ 提示需重新授权，不崩溃

### F-10 隐私验证
1. 用 PCAPdroid 抓本机流量，筛选 UID = SplashGuard
2. ✅ 只有 UDP:53 出站，无 HTTP/HTTPS 出站

- [ ] 冷启动 3 个常用 App，功能是否正常（登录、图片加载、播放）
- [ ] 关闭拦截后一切恢复
