# 真机验收操作手册

> 目标：把 `dist/SplashGuard-0.1.6.apk` 装到你的安卓手机上，跑完 5 步冒烟验证，  
> 把「诊断报告」发回来。全程约 10 分钟，不需要电脑（有电脑更快）。
>
> 适用：Android 8.0（API 26）及以上。华为鸿蒙、小米、OPPO、vivo、三星、原生均可。

---

## 一、这个 APK 是什么

| 项    | 值                                                                       |
| ---- | ----------------------------------------------------------------------- |
| 文件   | 桌面 `SplashGuard-0.1.6.apk`（推荐）；或 `dist/SplashGuard-0.1.6.apk`（约 4.8 MB） |
| 包名   | `com.splashguard.app`                                                   |
| 版本   | 0.1.6 (versionCode 6)                                                   |
| 签名   | 自签名（非商店分发）                                                              |
| 最低系统 | Android 8.0                                                             |
| 联网行为 | 只有 DNS 转发，无其他出站请求                                                       |

因为是自己签名的包，安装时系统会提示「未知来源应用」「未经安全检测」—— 这是所有非商店 APK 的  
正常提示，不是包有问题。确认继续安装即可。

## 二、怎么装到手机（三种方式，选一种）

### 方式 A：有电脑 + 数据线（最快，能看日志）

```bash
# 1. 手机开发者选项里打开「USB 调试」，插线，手机上点「允许调试」
adb devices
# 应看到一行 xxxxx  device

# 2. 安装
adb install -r dist/SplashGuard-0.1.6.apk
# 输出 Success 即成功
```

### 方式 B：微信 / QQ 传给自己（不用数据线，但要用到电脑）

**先找到文件** —— 下面三处内容完全相同，任选一处：

- 电脑桌面：`SplashGuard-0.1.6.apk`
- 电脑桌面：`SplashGuard-0.1.6.zip`（微信专用，推荐，原因见下）
- 项目目录：`D:\vs-document\SplashGuard\dist\SplashGuard-0.1.6.apk`

**微信的坑：微信会把 `.apk` 自动改名成 `.apk.1`**（防止自动安装），所以很多人发过去之后  
在手机端「找不到文件」或点开提示「无法打开」。zip 压缩包不会被改名。

推荐走 zip：

1. 电脑微信 →「文件传输助手」→ 发送 `SplashGuard-0.1.6.zip`
2. 手机微信里点开该 zip →「用其他应用打开」→ 选系统的「文件管理」
3. 解压出 `SplashGuard-0.1.6.apk` → 点击安装
4. 若提示「禁止安装未知应用」，点提示去开启本来源的安装权限，回来重试

如果坚持直接传 apk：手机文件管理进 `Download/WeiXin/` 找到 `SplashGuard-0.1.6.apk.1`，  
**重命名把结尾的 `.1` 删掉**，再点开就能装。

> QQ 传文件通常不加后缀，比微信省事。也可以用手机 QQ / 钉钉的「传文件到手机」。

### 方式 C：数据线拷到手机

把 APK 复制到手机 `Download/` 目录 → 用系统「文件管理」找到它 → 点击安装。

> 三种方式装出来的东西完全一样，只是方式 B/C 拿不到 logcat。冒烟验证不需要 logcat。

## 三、装完必须做的 4 件事

前两件不做功能不完整，后两件不做会被系统杀掉后台。

### ① 第一次打开点开关 → 允许 VPN

- 会弹出系统「连接请求」对话框，标题含 SplashGuard
- 必须点**确定/允许**，点取消就一直开不起来
- 成功后：状态文字变「运行中」，**状态栏出现钥匙图标**（这是 VPN 生效的标志）

### ② 开启无障碍（自动跳过功能，可选但建议）

**最快的办法：打开 SplashGuard，点首页第三个按钮「自动跳过」** —— App 会直接跳到系统的无障碍  
设置页，还会先弹一份带机型提示的引导，不用自己一层层翻菜单。

如果手动找，路径是：`系统设置 → 无障碍 → 已下载的服务 → SplashGuard 自动跳过 → 开启`

- 会弹「此服务可以查看屏幕内容」的警告，这是无障碍服务的标准提示
- 我们只做一件事：识别「跳过」两个字并点击，不读聊天记录、不读密码框
- 不开启也能用，只是少了「自动点跳过」这一层
- 开启成功后，首页那个按钮文字会变成「**自动跳过 · 开**」，用这个判断有没有生效

#### 小米 / Redmi / HyperOS 专用（小米 13 Pro 等）

小米把无障碍藏&#x5728;**「更多设置」**&#x91CC;，而且会把侧载安装的应用折叠起来，按这个顺序试：

1. 设置**顶部搜索框**直接搜「无障碍」→ 进「无障碍」→ 往下翻到「已下载的服务」
2. 或：设置 → **更多设置** → 无障碍 → 已下载的服务
3. **找不到就往下翻「更多已下载的服务」** —— HyperOS 常把非应用商店装的应用塞进这个折叠项，  
   这正是「列表里没有 SplashGuard」的最常见原因
4. 确认 App 真的装上了：设置 → 应用设置 → 应用管理 → 搜 `SplashGuard`。没装上的话列表里当然没有

#### 实在找不到：用电脑一条命令开启 / 修复

手机开 USB 调试并连电脑，在电脑上执行（App 里点「自动跳过」→「复制 ADB 命令」会自动复制这一条）：

```bash
adb shell 'comp=com.splashguard.app/com.splashguard.app.a11y.SkipAccessibilityService; cur=$(settings get secure enabled_accessibility_services); [ "$cur" = "null" ] && cur=""; without=$(echo "$cur" | sed "s#$comp:##g; s#:$comp##g; s#$comp##g; s/^://; s/:$//"); settings put secure enabled_accessibility_services "$without"; sleep 1; settings put secure enabled_accessibility_services "${without:+$without:}$comp"; settings put secure accessibility_enabled 1'
```

这条命令会先移除本服务、再重新加入，**保留 TalkBack 等其他无障碍服务**；既能首次开启，也能修复「显示已授权、实际没运行」的状态。

执行完回到 App 看按钮是否变成「自动跳过 · 开」。

#### 更新 App 后「一个都不跳过」怎么办

v0.1.6 会自己处理大部分情况：

- 打开 SplashGuard，如果按钮显示「**自动跳过 · 未连接**」，点它 →「一键修复」（需要下面的一次性授权）。
- 没给权限时，点「复制 ADB 命令」，在电脑上执行上面的命令即可。
- App 更新后，如果服务原本就在系统列表里，`MY_PACKAGE_REPLACED` 也会自动重新绑定。

一次性授权（可选，用来「一键修复」和「一键隐藏无障碍按钮」）：

```bash
adb shell pm grant com.splashguard.app android.permission.WRITE_SECURE_SETTINGS
```

这只是允许 App 读写**系统无障碍开关**，不读账号/密码，也不联网。

#### 屏幕上的「无障碍」悬浮按钮

那个按钮是 Android 系统的「无障碍快捷方式」，不是 SplashGuard 画的悬浮窗；关掉它不会关掉自动跳过。

- 手动关：设置 → 无障碍 → 无障碍快捷方式 → 关闭
- 或：打开 SplashGuard → 点「自动跳过」→「一键隐藏」（需要上面的一次性授权）

> **小米特别注意**：部分 HyperOS 版本会拦截 adb 修改 `secure` 设置，需要在  
> 开发者选项里额外打开「**USB 调试（安全设置）**」才生效（该开关要求登录小米账号）。  
> 如果执行后仍不生效，就回到上面的「更多已下载的服务」手动找。

华为 / 荣耀还需要到「应用启动管理」把本应用设为手动管理、三项全允许，否则后台会被杀。

### ③ 关掉电池优化（关键，否则后台被杀）

| 系统                  | 路径                                                        |
| ------------------- | --------------------------------------------------------- |
| 原生 Android / Pixel  | 设置 → 应用 → SplashGuard → 电池 → 不限制                          |
| 小米 HyperOS / MIUI   | 设置 → 应用设置 → 应用管理 → SplashGuard → 省电策略 → **无限制**；同时打开「自启动」 |
| 华为 HarmonyOS / EMUI | 设置 → 应用 → 应用启动管理 → SplashGuard → 关掉「自动管理」→ 手动管理里三项全开      |
| OPPO ColorOS        | 设置 → 电池 → 应用耗电管理 → SplashGuard → 允许后台运行 + 允许自启动           |
| vivo OriginOS       | 设置 → 电池 → 后台耗电管理 → SplashGuard → 允许后台高耗电                  |
| 三星 One UI           | 设置 → 电池 → 后台使用限制 → 把 SplashGuard 从「休眠应用」里移除               |

### ④ 确认开机自启已开（App 内「规则」页最下方）

默认是开的。作用：重启手机后自动恢复拦截，不用手动点。

## 四、5 步冒烟验证（10 分钟，必须全过）

> 每一步都写了「期望」和「不过怎么办」。任意一步不过，先记下来，继续往下走 ——  
> 最后一起发报告，不用当场排查。

### 第 1 步：开关能开、能关

1. 打开 SplashGuard，点右上开关
2. **期望**：状态变「运行中」，状态栏出现钥匙图标
3. 再点一次关掉
4. **期望**：钥匙图标消失，手机能正常上网

**不过怎么办**：如果点了开关没反应、或一直转圈，记下机型 + 系统版本。

---

### 第 2 步：DNS 拦截真的生效（核心）

> ⚠️ **别用 `ads.pangle.io` 这类域名做验证**。它们是广告 SDK 的接口域名，本来就不提供网页，
> 用浏览器访问**永远是「网页无法访问」**，跟拦不拦截没有任何关系。早期版本的手册写成用它验证，
> 是错的，特此更正。

正确做法是拿一个**确定能正常打开的网站**做对照：

0. 先访问 `https://example.com`，确认能打开（这是对照基准，证明网络本身是通的）
1. 确保开关是「运行中」
2. 进 SplashGuard →「规则」→ 在「自定义规则」里加一行 `example.com` → 保存
3. 浏览器再访问 `https://example.com`
4. **期望**：打不开（显示无法访问 / 连接被拒绝 / 空白页）
5. 回到 SplashGuard 首页
6. **期望**：「今日拦截」数字变大，「最近拦截」列表里出现 `example.com`
7. 测完把那行规则删掉，保存

> 如果 `example.com` 在你的网络下打不开，换成 `baidu.com` 做同样的事（会短暂影响百度系应用，
> 测完立刻删规则即可）。

这一步证明整个拦截链路是通的。**如果第 3 步打不开、但第 6 步没有记录**，说明 DNS 没被接管，
通常是 VPN 没真正建立（看状态栏有没有钥匙图标）。

**不过怎么办**：

- 页面能正常打开 → 拦截没生效，大概率 VPN 授权失败或隧道没建起来
- 打不开但没有日志 → 可能是浏览器用了自己的 DNS（部分国产浏览器内置 HTTPDNS），
  换 Chrome 或系统浏览器再试

---

### 第 3 步：关掉拦截能恢复（证明可逆、不是把网搞坏了）

1. 关掉开关，**等 60 秒**
2. 浏览器再访问刚才那个域名（`example.com` 或 `baidu.com`）
3. **期望**：能打开

**为什么必须等 60 秒**：拦截响应里带的 TTL 是 60 秒，系统 DNS 缓存会把这 60 秒内所有查询都
直接喂给你一个 `0.0.0.0`。所以刚关掉开关就立刻访问，**依然打不开是正常的**，不是隧道没拆干净。
换个从没访问过的域名则不需要等。

**真正的故障判断标准**：关掉开关后，随便打开一个从没访问过的网站（或直接用微信/淘宝），
能正常用就说明隧道拆干净了。用户反馈的「关掉也打不开」正是这两个原因（用了广告接口域名 +
60 秒 DNS 缓存）叠加的结果，不是缺陷。

**不过怎么办**：如果关掉开关、等够 60 秒、换新域名后仍然全部无法上网，才是严重问题
（隧道没拆除），立刻记下来。

---

### 第 4 步：真实 App 的开屏表现（最重要，也最主观）

准备：从最近任务里把目标 App **划掉**（确保是冷启动，不是从后台恢复）。

选 3 个你常用的、有开屏广告的 App（推荐 B 站 / 知乎 / 微博 / 小红书 / 淘宝）。

**先测「只开 DNS」：**

1. 关闭无障碍（系统设置里关掉 SplashGuard 自动跳过）
2. 冷启动 App，观察：开屏还在吗？停留几秒？
3. 记录下来

**再测「DNS + 自动跳过」：**

1. 打开无障碍
2. 再次冷启动同一个 App
3. 观察：是否被自动点掉？快了多少？

**期望**：至少有一个 App 明显变快或开屏消失。

**请注意这不是 bug 的几种情况**：

- 有些 App 的开屏是自绘的（Flutter/游戏引擎），无障碍读不到文字，只能靠 DNS
- 有些 App 用 HTTPDNS 直连，DNS 拦不住，只能靠无障碍点击
- 有些 App 素材失败后显示「跳过」占位等 3 秒 —— 这是 App 自己的降级策略，不是我们没生效

把每个 App 的实际表现填进下表（不用很精确，感觉就行）：

| App  | 只开 DNS | 开 DNS + 跳过 | 备注      |
| ---- | ------ | ---------- | ------- |
| qq音乐 | 有效果    | 有效果        | 很快      |
| 懂球帝  | 无效果    | 无效果        | 一点效果都没有 |
| 哔哩哔哩 | 有效果    | 有效果        | 很快      |

### 第 5 步：导出报告发回来

1. 回到 SplashGuard 首页
2. 点「最近拦截」右边&#x7684;**「导出报告」**
3. 弹窗里有完整诊断信息，点「复制全文」或「分享 / 存文件」
4. 发给我（微信/邮件都行）

报告里包含：机型、系统版本、ROM、拦截开关状态、规则数、分应用选择、无障碍状态、  
今日拦截数、最近 200 条拦截日志。**不含任何账号、位置、通讯录信息。**

有了这份报告，我就能判断你的设备上是哪一环没生效。

## 六、出问题怎么排查

### 钥匙图标不出现

VPN 没建立。依次检查：

1. 系统设置 → VPN → 是否有 SplashGuard 条目（没授权过就没有）
2. 是否有其他 VPN/代理类 App 在运行（**同一时间只能有一个 VPN**，这是 Android 硬限制）
3. 是否装了企业 MDM / 工作资料（会占用 VPN 通道）
4. 重启手机再试

### 拦截数字一直是 0

1. 先确认第 2 步能复现
2. 检查是不是切到了「仅选中的应用」但一个都没勾 —— 这种情况下只有勾选的 App 会被过滤
3. 部分 App 用 HTTPDNS / DoH 绕过系统 DNS，这类拦不到（已知边界）

### 无障碍开了但从不点击

1. 系统设置 → 无障碍 → 确认 SplashGuard 自动跳过是「已开启」状态（不是只是装了）
2. **看 App 首页按钮是「自动跳过 · 开」还是「自动跳过 · 未连接」**：
   - 未连接 = 系统列表里有、但服务没运行。点按钮 →「一键修复」，或复制 ADB 命令执行
   - 更新 App 后最常见的就是这个状态；v0.1.6 会在打开 App 时自动尝试修复一次
3. 目标 App 的开屏是自绘的 → 无障碍树里没有「跳过」文字节点，读不到就是点不到

### 后台一段时间后失效

电池优化没关。回到「三、④」按机型设置。

## 七、已知边界（不是 bug，做不到就是做不到）

| 场景                           | 为什么                                                              |
| ---------------------------- | ---------------------------------------------------------------- |
| 开屏是 Flutter / Unity / 游戏引擎自绘 | 无障碍树里没有文字节点，读不到「跳过」                                              |
| App 用 HTTPDNS / DoH 直连广告商    | 不走系统 DNS，DNS 层拦不到                                                |
| 摇一摇跳转                        | 广告 SDK 直接读加速度计，**Android 无公开 API 可阻止**；只能靠「抢在抖动前点掉」和「素材加载失败」间接规避 |
| 同时开着其他 VPN                   | Android 同一时间只允许一个 VPN 通道                                         |
| 部分系统 App 的启动页                | 系统级界面，无障碍不可见                                                     |

## 八、卸载与还原

- 卸载 App：长按图标卸载，或 设置 → 应用 → SplashGuard → 卸载
- 卸载后 DNS 立即恢复运营商默认，无残留
- 若之前开过无障碍，卸载时系统会自动移除该服务
- 日志文件在应用私有目录，随卸载一起删除
